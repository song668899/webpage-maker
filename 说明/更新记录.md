## 2026-09-30

- 启动 GitHub 部署准备（命令行路线）：
  - 在 `D:\网页制造` 执行 `git init -b main`，本地仓库已建立（`main` 分支，尚无提交）
  - **待办**：配置全局 Git 身份（`user.name` / `user.email`）、创建远端仓库、首次提交与推送、开启 GitHub Pages
  - 提醒：`.arts/`、`.codeartsdoer/`、`.merkle-snapshot.json` 是工具生成的产物，提交前应排除（已建 `.gitignore`）
- 扫雷补齐三处体验短板（参考 GitHub 上 ShizukuIchi/minesweeper 的 Windows XP 复刻做法）：
  - **加难度选择**：顶部三档 tab —— 简单 8×8/10 雷、中等 12×12/25 雷、困难 16×16/45 雷，切难度即开新局
  - **踩雷反馈重做**：踩中的雷红底 + 放大脉冲 + 💥，其余雷区分显示，**插错的旗子打 ❌**，外加棋盘抖动 + 全屏红闪 + 三段震动
  - **结算重做**：不再立刻盖住棋盘，**延迟 0.9 秒**让你先看清炸点；改成**底部抽屉**（棋盘仍可见），并显示用时 / 难度 / **本机最佳记录**，按钮为「再来一局」「看看棋盘」
  - 最佳记录存 `localStorage`，按难度分别记
- 扫雷改为手机友好版：
  - 难度从 9×9 调整为 **8×8**，格子在手机上从 39px 提升到 45px 左右（触控标准是 44px）
  - 格子尺寸由 JS 按屏幕实时计算，横竖屏都会重新布局
  - 新增**「标记模式」按钮**：点一下切换，之后点格子即插旗，不用再长按（手机扫雷标准做法）
  - 长按阈值从 500ms 放宽逻辑到 400ms，并加了**按下高亮**和**震动反馈**（安卓）
  - 触摸与鼠标统一走 Pointer Events，修掉"点击被触发两次"的隐患
  - 滑动超过 12px 视为滚动，不触发翻开，避免误触
  - 适配 iPhone 安全区（`env(safe-area-inset-*)`）和横屏
  - 胜利/失败也加了震动
