# 网页制造 · 总览

一个用链接分享的互动网页合集：把链接发给对方，点开即可体验，不用安装任何东西。

## 一、目录结构

```
网页制造/
├─ index.html            总入口：读 ?m= 参数决定进哪个界面，不带参数则显示菜单
├─ 表白/                 表白模块
│   ├─ index.html
│   ├─ style.css
│   ├─ script.js
│   └─ assets/           音乐等素材放这里
├─ 游戏/                 扫雷模块
│   ├─ index.html
│   ├─ style.css
│   └─ script.js
└─ 说明/                 本目录，项目文档
```

分类规则：**顶层文件夹 = 一个玩法，各自自带完整文件、互不干扰。**
分类维度统一为「送出去干嘛」：表白 / 祝福 / 游戏。

## 二、模块清单

| 参数 | 名称 | 路径 | 状态 |
| --- | --- | --- | --- |
| 无 | 菜单 | `index.html` | 可用 |
| `?m=love` | 表白 | `表白/` | 可用 |
| `?m=wish` | 祝福 | `祝福/` | 待开发 |
| `?m=game` | 游戏 | `游戏/` | 可用 |

规则：**文件夹名用中文，URL 参数 id 用英文**。因为中文在链接里会变成
`%E8%A1%A8%E7%99%BD` 这种乱码串，发给别人不好看；英文 id 干净。

## 三、本地预览

入口页用 iframe 加载子页面，直接双击 `index.html` 会被浏览器的跨文件限制拦住，
所以要在项目根目录起一个本地服务：

```
cd D:\网页制造
python -m http.server 8123
```

然后浏览器打开 <http://127.0.0.1:8123/>

> 单独看表白页可以不走入口：直接双击 `表白/index.html` 也能打开。

## 四、发布到 GitHub Pages

1. 把整个 `网页制造` 文件夹推到 GitHub 仓库
2. 仓库 Settings → Pages → 选择分支和根目录
3. 得到地址 `https://用户名.github.io/仓库名/`
4. 分享时带上参数，例如 `https://用户名.github.io/仓库名/?m=love`

注意：**传整个文件夹**，不是只传一个 index.html。

## 五、常见修改对照

| 想改什么 | 去哪改 |
| --- | --- |
| 表白文案 | `表白/script.js` 顶部 `CONFIG.message` / `CONFIG.subMessage` |
| 表白配色 | `表白/script.js` 顶部 `CONFIG.palette` |
| 表白音乐 | 把 mp3 放进 `表白/assets/`，命名 `music.mp3` |
| 爱心粒子数量 | `表白/script.js` 的 `CONFIG.heartParticles` |
| 心跳快慢/幅度 | `表白/script.js` 的 `HEART.pulseSpeed` / `pulseAmple` |
| 菜单里有哪几项 | 根 `index.html` 里的 `MODULES` 列表 |

## 六、加一个新玩法

1. 在根目录新建文件夹（中文名），放好它的 `index.html`
2. 打开根 `index.html`，在 `MODULES` 列表里加一行，并把 `ready` 改成 `true`
3. 完成——菜单自动出现，`?m=xxx` 自动可用

```js
var MODULES = [
  { id: 'love', name: '表白', path: '表白/index.html', ready: true },
  { id: 'wish', name: '祝福', path: '祝福/index.html', ready: false },
  { id: 'game', name: '游戏', path: '游戏/index.html', ready: true }
];
```
