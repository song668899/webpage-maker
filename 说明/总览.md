# 网页制造 · 总览

一个用链接分享的互动网页合集：把链接发给对方，点开即可体验，不用安装任何东西。

## 一、目录结构

```
网页制造/
├─ index.html            总入口：?m= 决定进哪个大模块，不带参数显示菜单
├─ 祝福/                 祝福大模块
│   ├─ index.html        模块菜单：?p= 决定进哪个子项目，不带参数显示列表
│   ├─ style.css / script.js
│   ├─ 表白/             子项目
│   │   ├─ index.html
│   │   ├─ style.css / script.js
│   │   └─ assets/       音乐等素材
│   └─ 国庆/             子项目（烟花之夜）
│       ├─ index.html
│       ├─ style.css / script.js
│       └─ assets/       音乐等素材（自建，放 music.mp3）
├─ 游戏/                 游戏大模块（结构与祝福完全对称）
│   ├─ index.html + style.css + script.js
│   └─ 扫雷/             子项目
│       └─ index.html + style.css + script.js
└─ 说明/                 本目录，项目文档
```

分类规则：**顶层文件夹 = 一个大模块（送出去干嘛：祝福 / 游戏 / 纪念），
模块内子文件夹 = 一个具体玩法**。子项目自带完整文件、互不干扰。

## 二、链接结构（两层路由）

| 链接参数 | 进哪 |
| --- | --- |
| 无参数 | 根菜单（祝福 / 游戏 / 纪念） |
| `?m=wish` | 祝福模块菜单（表白 / 国庆 / 春节） |
| `?m=wish&p=love` | 直达表白 |
| `?m=wish&p=guoqing` | 直达国庆（烟花之夜） |
| `?m=game` | 游戏模块菜单（扫雷） |
| `?m=game&p=mines` | 直达扫雷 |
| `?m=mem` | 纪念（待开发占位，灰显） |

规则：**文件夹名用中文，URL 参数值用英文**。中文在链接里会变成
`%E8%A1%A8%E7%99%BD` 这种乱码串，发给别人不好看；英文 id 干净。

**分享语义（两种链接行为不同）**：

| 你发的链接 | 对方看到什么 |
| --- | --- |
| 带 `&p=` 的直达链接（如 `?m=wish&p=guoqing`） | **只有这个子项目**，左上/左下无返回按钮，封闭体验 |
| 不带 `p` 的总菜单（`?m=wish` 或根路径） | 菜单可随便点进各个玩法，**每个子项目都有返回按钮** |

机制：初始 URL 带 `p` 即视为分享直达，根入口透传 `direct=1` 给 iframe 链
→ 子页面读到 `direct=1` 就隐藏返回按钮。从菜单点进来的 `p` 与初始值不同，不透传。

导航细节（改动时注意）：
- 子页面左上/左下有**返回按钮**，经 `postMessage` 通知总入口改地址栏（跨 iframe 层级）
- 总入口用 `pushState` + `route()`，前进/后退键可用
- iframe 内部跳转一律用 `location.replace()`，**不产生历史条目**（否则返回键要按两次）

## 三、本地预览

入口页用 iframe 加载子页面，直接双击 `index.html` 会被浏览器的跨文件限制拦住，
所以要在项目根目录起一个本地服务：

```
cd D:\网页制造
python -m http.server 8123
```

然后浏览器打开 <http://127.0.0.1:8123/>

> 子项目页面可以不走入口：直接双击 `祝福/表白/index.html`、`游戏/扫雷/index.html` 也能打开
> （此时返回按钮自动隐藏）。

## 四、发布到 GitHub Pages

> **本项目已上线**：<https://song668899.github.io/webpage-maker/>

流程备忘（再次部署时用）：

1. 把整个 `网页制造` 文件夹推到 GitHub 仓库
2. 仓库 Settings → Pages → 选择分支和根目录
3. 得到地址 `https://用户名.github.io/仓库名/`
4. 分享时带上参数，例如 `https://用户名.github.io/仓库名/?m=wish&p=love`

注意：**传整个文件夹**，不是只传一个 index.html。

## 五、常见修改对照

| 想改什么 | 去哪改 |
| --- | --- |
| 表白文案 | `祝福/表白/script.js` 顶部 `CONFIG.message` / `CONFIG.subMessage` |
| 表白配色 | `祝福/表白/script.js` 顶部 `CONFIG.palette` |
| 表白音乐 | 把 mp3 放进 `祝福/表白/assets/`，命名 `music.mp3` |
| 爱心粒子数量 | `祝福/表白/script.js` 的 `CONFIG.heartParticles` |
| 心跳快慢/幅度 | `祝福/表白/script.js` 的 `HEART.pulseSpeed` / `pulseAmount` |
| 国庆文案/轮播句 | `祝福/国庆/script.js` 顶部 `CONFIG.message` / `CONFIG.lines` |
| 国庆烟花配色/频率 | `祝福/国庆/script.js` 的 `CONFIG.palette` / `CONFIG.autoFirework` |
| 国庆音乐 | 自建 `祝福/国庆/assets/`，放 `music.mp3`（目录默认不存在） |
| 孔明灯数量 | `祝福/国庆/script.js` 的 `CONFIG.lanterns` |
| 扫雷难度档 | `游戏/扫雷/script.js` 顶部 `LEVELS` |
| 根菜单有哪几个大模块 | 根 `index.html` 里的 `MODULES` 列表 |
| 祝福模块里有哪几项 | `祝福/script.js` 的 `ITEMS` 列表 |
| 游戏模块里有哪几项 | `游戏/script.js` 的 `ITEMS` 列表 |

## 六、加一个新玩法

**加到已有模块**（例如游戏模块加「扫雷 2」）：

1. 在模块文件夹下新建子文件夹（中文名），放好它的 `index.html`
2. 打开该模块的 `script.js`，在 `ITEMS` 列表加一行，`ready` 改 `true`
3. 完成——菜单自动出现卡片，`?m=game&g=xxx` 自动可用

```js
var ITEMS = [
  { id: 'mines', name: '扫雷', desc: '三档难度，长按或标记模式插旗', path: '扫雷/index.html', ready: true },
  { id: 'xxx', name: '新游戏', desc: '一句话介绍', path: '新游戏/index.html', ready: true }
];
```

**加一个全新大模块**：在根目录新建文件夹 + 根 `index.html` 的 `MODULES` 加一行，
并复制 `游戏/` 的三件套作为模块菜单即可。
