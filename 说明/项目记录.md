## 一、项目背景

**核心需求**：做一个可通过链接分享的互动网页，对方点开即可体验，不用安装任何东西。

**分发渠道**：微信（聊天、朋友圈）+ 普通浏览器。

**载体**：纯 HTML / CSS / JavaScript，零依赖，零构建。

**设计决策**：
- 不选 Python（微信不支持）
- 不选小程序（需账号+审核，太重）
- 不选后端（纯静态，省事）

## 五、技术细节

### 5.1 入口页路由

```js
var MODULES = [
  { id: 'love', name: '表白', path: '表白/index.html', ready: true },
  { id: 'wish', name: '祝福', path: '祝福/index.html', ready: false },
  { id: 'game', name: '游戏', path: '游戏/index.html', ready: true }
];
```

- 不带 `?m=` 参数 → 显示菜单
- 带 `?m=love` → 直接进入表白
- 带 `?m=wish` 但 `ready: false` → 显示"待开发"

### 5.2 帧率归一化

```js
var dt = Math.min((now - lastFrame) / 1000, 0.05);
var ds = dt * 60;  // 以 60fps 为基准

// 所有物理更新都乘 ds
p.vx += (tx - p.x) * p.spring * ds;
p.x += p.vx * ds;
```

**原因**：120Hz 高刷手机上，不归一化会导致动画速度翻倍。

### 5.3 弹簧物理

```js
// 线性逼近（旧）
p.x += (tx - p.x) * ease;  // 固定系数，高刷屏速度翻倍

// 弹簧物理（新）
p.vx += (tx - p.x) * spring;   // 加速度
p.vx *= damping;               // 阻尼
p.x += p.vx * ds;              // 位移
```

**效果**：有惯性、会过冲、会回弹，比线性逼近生动。

### 5.4 弧长均匀采样

```js
function sampleByArc(poly, n) {
  // 1. 把多边形拆成线段，累计每段弧长
  // 2. 按总弧长均匀取点
  // 3. 返回 n 个点
}
```

**原因**：心形参数方程按 `t` 均分，尖角处点扎堆、弧顶处稀疏。弧长采样保证点距一致。

### 5.5 沿轮廓流动

```js
var off = tSec * flowSpeed;  // 随时间偏移
var fi = (p.i + off * p.flow) % N;
```

**效果**：粒子顺着边缘缓慢"跑"，爱心像在呼吸转动。

### 5.6 触摸推开粒子

```js
var R = Math.min(W, H) * pointerRadius;
var R2 = R * R;

if (pointer.active) {
  var dx = p.x - pointer.x;
  var dy = p.y - pointer.y;
  var d2 = dx * dx + dy * dy;
  if (d2 < R2) {
    var d = Math.sqrt(d2) || 1;
    var f = Math.pow(1 - d / R, 2) * pointerForce * ds;
    p.vx += dx / d * f;
    p.vy += dy / d * f;
  }
}
```

**效果**：鼠标划过 / 手机触摸拖动，粒子被拨开再弹回。

## 七、优化记录

### 2026-09-29 优化版

| 问题 | 解决方案 |
| --- | --- |
| 高刷屏（120Hz）动画速度翻倍 | 帧率归一化（`dt`） |
| 粒子匀速逼近，没惯性 | 弹簧物理（弹性 + 阻尼） |
| 心形轮廓点距不均 | 弧长均匀采样 |
| 爱心静态不动 | 沿轮廓流动 + 整体摆动 |
| 触摸无反馈 | 指针推开粒子 |
| 单帧报错整页停摆 | 加 `try-catch` 兜底 |
| 粒子颜色精灵可能不存在 | 加 `if (!spr) continue` 检查 |

## 九、常见问题

### Q1：本地双击 `index.html` 打不开？

**原因**：入口页用 iframe 加载子页面，直接双击会被浏览器的跨文件限制拦住。

**解决**：
```
cd D:\网页制造
python -m http.server 8123
```
然后浏览器打开 <http://127.0.0.1:8123/>

### Q2：表白页双击能打开，但动画不显示？

**原因**：点击"轻触开启"触发了爆粒子，但 `draw` 参数错位，第一帧就抛错。

**解决**：已修复。确保 `createParticleField` 接收 `sprites` 参数，`draw` 方法只接收 `ctx`。

### Q3：微信里打不开？

**原因**：微信内置浏览器只认 `https://` 链接，不认本地文件。

**解决**：必须部署到 GitHub Pages 或国内云托管，拿到 `https://` 地址。

### Q4：手机卡顿？

**原因**：粒子数量过多。

**解决**：调小 `CONFIG.heartParticles`（默认 820）。

### Q5：音乐不响？

**原因**：微信必须先点一下才允许播放音频。

**解决**：已做启动遮罩，点击"轻触开启"后播放。如果还是不响，检查 mp3 文件是否存在。
